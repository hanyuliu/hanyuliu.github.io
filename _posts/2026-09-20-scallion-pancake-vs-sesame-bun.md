我有一个 Vibe Coding 布道师朋友，他见我就问："古法编程的屎山也多了去了，你怎么专挑 vibe coding 黑？"

我：不一样。古法编程的屎山像千层饼，一层一层堆上去的，有地质结构的层次特征。配上 git log，你还能考古，层与层之间的逻辑是找得到的。Vibe coding 的屎山像芝麻酱花卷，你 coding 一次，新屎老屎就从头到尾揉一遍，最后拧成一团。千层饼你能一层一层揭开，花卷……你连从哪儿下口都不知道。

他想了想：那我让 AI 重构一下不就行了？

我：……那是再抹一层芝麻酱，再揉一遍。
